# 🌦️ Weather Now - Modern Weather Dashboard

ეს არის თანამედროვე, სრულად რესპონსიული ამინდის პროგნოზის აპლიკაცია, რომელიც შექმნილია **Mobile First** პრინციპით. პროექტი ფოკუსირებულია სუფთა ინტერფეისზე, ლამაზ ვიზუალსა და საუკეთესო User Experience-ზე.

## ✨ ფუნქციები (Features)

- **📱 Mobile-First Design**: აპლიკაცია იდეალურად მორგებულია ნებისმიერი ზომის ეკრანზე (მობილური, ტაბლეტი, დესკტოპი).
- **🎨 Modern UI/UX**: გამოყენებულია მუქი (Dark Mode) ესთეტიკა, გრადიენტები და დახვეწილი ჩრდილები (Shadows).
- **📅 Daily Forecast**: 7-დღიანი ამინდის პროგნოზი შესაბამისი ხატულებითა და ტემპერატურის მაჩვენებლებით.
- **⏰ Hourly Forecast**: საათობრივი განრიგი გვერდითა პანელში (დესკტოპზე) ან ქვემოთ (მობილურზე).
- **📊 Real-time Stats**: დამატებითი ინფორმაცია - ჰაერის ტენიანობა, ქარის სიჩქარე, ნალექი და ა.შ.
- **🔍 Search**: ლოკაციის მიხედვით ამინდის ძიების შესაძლებლობა.

## 🛠️ ტექნოლოგიები (Technologies)

- **HTML5**: სემანტიკური სტრუქტურა.
- **Tailwind CSS**: სწრაფი და ეფექტური სტილიზაციისთვის.
- **Google Fonts (Inter)**: სუფთა და კითხვადი ტიპოგრაფიისთვის.
- **WebP Icons**: მაღალი ხარისხის და ოპტიმიზირებული ვიზუალური ელემენტები.

## 🚀 როგორ გავუშვათ?

1. ჩამოტვირთეთ პროექტი.
2. გახსენით `weatherApp.html` ნებისმიერ ბრაუზერში.
3. (სურვილისამებრ) გამოიყენეთ Live Server VS Code-ში უკეთესი გამოცდილებისთვის.
