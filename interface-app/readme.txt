----------------------------------------------------------------------
ნაწილი 1: ფაილი INTERFACE.TS
----------------------------------------------------------------------
ეს ფაილი განსაზღვრავს ჩვენი პროგრამის "ჩონჩხს" – ანუ რა ფორმის და სტრუქტურის 
უნდა იყოს მონაცემები, რომლებსაც პროგრამაში გამოვიყენებთ.

1. კატეგორიის ტიპი (category)
   * კოდი: export type category = ('Electronics' | 'Clothing' | 'Books');
   * განმარტება: ეს არის Union (გაერთიანების) ტიპი. ის კრძალავს ნებისმიერი სხვა 
     ტექსტის ჩაწერას, გარდა ამ სამი კონკრეტული სიტყვისა.

2. პროდუქტის მოდელი (IProduct)
   * კოდი:
     export interface IProduct {
         id: number,
         name: string,
         price: number,
         category: category
     };
   * განმარტება: აღწერს რა ველები აქვს პროდუქტს. ფასი (price) აუცილებლად არის 
     რიცხვი (number), რომ მასზე მათემატიკური გამოთვლები შევძლოთ.

3. კალათის ელემენტი (ICartItem)
   * კოდი:
     export interface ICartItem {
         product: IProduct,
         quantity: number
     };
   * განმარტება: კალათაში ინახება არა უბრალოდ პროდუქტის სახელი, არამედ მთლიანი 
     პროდუქტის ობიექტი (IProduct) და მისი რაოდენობა (quantity).

4. მომხმარებლის სტატუსი (userstatus) და მოდელი (IUser)
   * კოდი: export type userstatus = ('Guest' | 'Regular' | 'VIP');
   * განმარტება: მომხმარებელს შეიძლება ჰქონდეს მხოლოდ ამ 3-დან ერთ-ერთი სტატუსი.
   * IUser ინტერფეისში აღწერილია უნიკალური ID, სახელი (name), მეილი (email) 
     და ზემოთ შექმნილი სტატუსი (status).

5. შეკვეთის მოდელი (IOrder)
   * განმარტება: აერთიანებს ყველაფერს:
     - id: შეკვეთის ნომერი.
     - user: ვინ იყიდა (IUser ტიპის ობიექტი).
     - items: რა იყიდა (ICartItem-ების მასივი).
     - fullprice: საბოლოო გადასახდელი ფასი (რიცხვი).
     - orderstatus: შეკვეთის მდგომარეობა ('Pending' | 'Shipped' | 'Delivered').
     - createdate: როდის შეიქმნა (დროის აღმნიშვნელი რიცხვი ან თარიღი).


----------------------------------------------------------------------
ნაწილი 2: ფაილი MAIN.TS
----------------------------------------------------------------------

1. იმპორტი (Import)
   * კოდი: import { IUser, ICartItem, IOrder, IProduct } from './interface';
   * განმარტება: `interface.ts` ფაილიდან გადმოაქვს ჩვენ მიერ შექმნილი წესები, 
     რომ `main.ts`-მაც იცოდეს, როგორ მუშაობს ეს ტიპები.

2. ფუნქცია: calculateDiscount (ფასდაკლების გამოთვლა)
   * როგორ მუშაობს: იყენებს მარტივ `if - else if - else` კონსტრუქციას.
   * ლოგიკა:
     - თუ მომხმარებლის სტატუსი არის 'VIP', ის ყოველთვის იღებს 15%-იან ფასდაკლებას:
       (კალათის ჯამი * 0.15).
     - თუ სტატუსია 'Regular' და კალათის ჯამი მეტია 100 ლარზე, ის იღებს 5%-ს:
       (კალათის ჯამი * 0.05).
     - ყველა სხვა შემთხვევაში (ტუ არის Guest ან თუ Regular-ის ჯამი 100-ზე ნაკლებია)
       აბრუნებს 0-ს (ფასდაკლება არ არის).

3. ფუნქცია: createOrder (შეკვეთის შექმნა)
   * ნაბიჯი ა (კალათის დაჯამება):
     ფუნქცია იყენებს `.reduce()` მეთოდს. ეს მეთოდი სათითაოდ უვლის კალათაში არსებულ 
     ყველა ნივთს, ამრავლებს ნივთის ფასს მის რაოდენობაზე (item.product.price * item.quantity) 
     და აჯამებს ერთ ცვლადში (`rawTotalPrice`).
   * ნაბიჯი ბ (ფასდაკლების გამოკლება):
     იძახებს `calculateDiscount` ფუნქციას, იგებს დასაკლებ თანხას და აკლებს საწყის ჯამს:
     `const finalPrice = rawTotalPrice - discount;`
   * ნაბიჯი გ (დამრგვალება):
     `Number(finalPrice.toFixed(2))` – `.toFixed(2)` ამრგვალებს ფასს მძიმის შემდეგ ორ 
     ნიშნამდე (თეთრებამდე), მაგრამ ხდის ტექსტად (string). წინ დაწერილი `Number(...)` 
     კი ამ ტექსტს ისევ რიცხვად აქცევს, რომ ინტერფეისის წესი არ დაირღვეს.
   * ნაბიჯი დ (ობიექტის დაბრუნება):
     აბრუნებს სრულყოფილ `IOrder` ობიექტს. ID გენერირდება შემთხვევითობით `Math.random()`-ით, 
     ხოლო შექმნის თარიღად იწერება მიმდინარე დრო `Date.now()` (მილიწამებში).


----------------------------------------------------------------------
ნაწილი 3: სატესტო მონაცემების მუშაობის პრინციპი
----------------------------------------------------------------------

1. მონაცემთა მასივები (Arrays):
   * `products: IProduct[]` — ერთ ცვლადში ინახება ჩვენი ყველა პროდუქტი.
   * `users: IUser[]` — ერთ ცვლადში ინახება ყველა ჩვენი სატესტო მომხმარებელი.
   * მასივიდან მონაცემს ვიღებთ ინდექსით: `products[0]` არის სმარტფონი, 
     ხოლო `users[1]` არის გელა (რადგან ათვლა იწყება 0-დან).

2. ტესტის ქეისები კონსოლში:
   * საბას შეკვეთა (users[0]): ყიდულობს სმარტფონს (250 ლარი). რადგან VIP-ია, 
     ფუნქცია დააკლებს 15%-ს და `fullprice` გამოვა 212.5.
   * გელას შეკვეთა (users[1]): ყიდულობს ჰუდს და წიგნს (120 + 45 = 165 ლარი). 
     რადგან Regular-ია და ჯამი 100-ზე მეტია, დააკლდება 5% და `fullprice` გამოვა 156.75.
   * ჯემალას შეკვეთა (users[2]): ყიდულობს ორ წიგნს (45 * 2 = 90 ლარი). რადგან 
     Guest-ია, ფასდაკლება იქნება 0 და `fullprice` დარჩება უცვლელი – 90 ლარი.
